Given a 64-bit integer, and two indices `i`, and `j` (consider 0-indexed from the LSB), swap the bits at positions `i` and `j`.

- A Brute force approach for this would go about like this:
    1. Find the `ith` bit.
    1. Find the `jth` bit.
    1. Store these 2 values into temporary variables.
    1. Write the value of `jth` bit into `ith` bit.
    1. Write the value of `ith` bit into `jth` bit.

But knowing that we are working with bits gives us some leverage. 
- First, if both the `ith` and `jth` bits are the same we can stop right there. Swapping is only needed when one of them is a zero and the other is a one.
- Second, unlike swapping in an array, swapping two (different) bits is the same as just flipping each bit. (XOR with 1).

So the best way to do this ?

```java
public static long swapBits(long x, int i, int j) {
    if( ((x >>> i) & 1) != ((x >>> j) & 1) ) {
        // If ith and jth bits are not the same

        long mask = (1L << i) | (1L << j);

        // Do the flip by XOR-ing with 1 at position i and j
        x ^= mask;
    }

    return x;
}
```

## Question
The problem here requires obtaining the number of bits that are `1` in the binary representation of any given integer.

## Solution
```java
// Java

public static int countOnes(int x) {
    int ans = 0;

    while(x != 0) {
        if(x & 1) ans++;
        ans = ans >>> 1;
    }

    return ans;
}
```

We take in the number as an argument and then keep right shifting it until it becomes `0`.
For every iteration in the loop, we check if the *Least Significant Bit(LSB)* is `1`. If yes, we increment the `ans` store, returning it at the end.

- One thing to take note here is that, Java sets the *Most Significant Bit(MSB)* of a negative number to `1` (pads the left ends of the number with `1` instead of `0`). So, performing a `>>` might cause a miscount. Hence, we use a `>>>` which essentially does a unsigned right shift, keeping the left most unused bits `0``.

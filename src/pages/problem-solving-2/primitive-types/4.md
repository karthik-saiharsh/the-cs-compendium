The weight of a number is defined as the number of high bits in the number. Weight of `5` i.e `0101` is `2`.
Given a number `x`, we need to find another number `y`, such that x and y have the same weight, and `|x-y|` is as small as possible.

- Let us start with the actual number. It already has the weight of itself.
- The bare minimum we need to do is move the position of a single bit (swap a single bit), and it would give us a new number with the same weight.
- The hard part is figuring out which bits to swap so that the difference is as small as possible.
- Since in a binary number the right-ier bits hold little weight while the left-ier bits hold more weight, it makes sense that we need to fiddle with the right-ier bits somehow.
- The actual solution is to find the rightmost 2 bits that are different and swap them.

```java
public static long closestWeight(long x) {
    for(int i=0; i < 63 - 1; i++ ) {
        // Check rightmost adjascent bits
        if( ((x >>> i)&1) != ((x >>> (i+1))&1) ) {
            // Swap the 2 bits
            long mask = (1L << i) | (1L << (i+1));
            x ^= mask;

            return x;
        }
    }
}
```

- We only iterate from `0` to `62` even though we have a 64-bit number is because the MSB is the sign bit in java, and we don't need to bother ourselves with that.

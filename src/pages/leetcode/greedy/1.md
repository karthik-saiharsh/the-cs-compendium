## Problem Overview
We are given a 2D array of boxes (box types). Each element in the array is of the form [number, number], where the first number is 
the type of the box(say t), and the second number is the number of units/items in each box of type  t.

We are given a value: `truckSize` which is basically the maxium number of boxes that can be loaded onto the truck.

**Goal:** Our goal with the problem is to basically maximize the number of units that can be squashed onto the truck without the number of boxes exceeding `truckSize`.

## Solution - Theory
This is a classic Greedy Problem, similar to the knapsack problem.

To solve this, we need to know which combination of boxes ends up having the maximum number of units while the count of boxes themselves is lower than `truckSize`.

So, we can sort the array by number of units in each box as key in decreasing order.

One this is done, we can now pick up boxes one by one from the front of the array, add them to our solution while we verify each time `truckSize` isn't hit.

We essentially pick the best solution there is in each iteration which is what makes this solution greedy.

## Solution  - Code

### Java
```java
import java.util.Arrays;
class Solution {
    public int maximumUnits(int[][] boxTypes, int truckSize) {
        Arrays.sort(boxTypes, (a, b) -> -(a[1] - b[1])); // Sort by decreasing order of units

        int ans = 0;
        // For each box picked by highest number of units
        for(int box[] : boxTypes) {
            int boxes = box[0];
            int units = box[1];

            if(truckSize <= 0) break;

            // Add the number of units to `ans` as long as more boxes can be accomodated
            if(boxes <= truckSize) {
                ans += (boxes * units);
                truckSize -= boxes;
            } else {
                ans += (truckSize * units);
                truckSize = 0;
            }
        }

        return ans;
    }
}
```



### Python
```python
class Solution:
    def maximumUnits(self, boxTypes: List[List[int]], truckSize: int) -> int:
        # Sort by units
        boxTypes = sorted(boxTypes, key = lambda box: -box[1])

        ans = 0

        # For each item in with highest units
        for item in boxTypes:
            boxes = item[0]
            units = item[1]

            if truckSize <= 0:
                return ans
            # Add units to answer if the box can be accomodated
            if boxes <= truckSize:
                ans += boxes * units
                truckSize -= boxes
            else:
                return ans + (truckSize * units)

        return ans
```

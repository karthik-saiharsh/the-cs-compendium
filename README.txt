# The CS Compendium

This is my attempt at compiling all of my knowledge of Computer Science in one place.
Though it is a singular effort on my part, any contributions from anyone on any topic are welcome.

There is no particular schedule or pattern of updates.
I will keep adding new sections and topics as I find the time.

Please note that I do not claim the content to be entirely original. This project is essentially my personal notebook, where I document what I learn and share it with everyone.
I will cite my sources whenever I write about something that has been explained by someone else.
